`@preprocess/cli` is the command-line bridge between your local git repository
and your Preprocess organization. Use it to bundle and deploy agents from a
laptop or CI, pull dashboard overrides and group slugs back into
`preprocess.config.json`, start cases against production or preview deployments,
stream run logs, compare models with eval suites, and install or upgrade a
self-hosted stack in your own Cloudflare account (`preprocess install`).

## Install

```sh
npm install --save-dev @preprocess/cli
```

## Sign in

The CLI reads three environment variables on every command:

<Configured
  lang="sh"
  code={`export PREPROCESS_API_URL={origin}
export PREPROCESS_ORG=org_...
export PREPROCESS_API_KEY=...`}
/>

- `PREPROCESS_API_URL` is the origin your organization's app is served from.
- `PREPROCESS_ORG` is your organization's id.
- `PREPROCESS_API_KEY` is an organization API key. An Owner or Admin creates one
  in Developers → Keys & webhooks. The key acts with Admin rights, so it can
  deploy, promote, and work cases (it cannot approve—approving always requires a
  person). Each key is shown once at creation, and the CLI reads it only from
  the environment so it never lands in shell history or CI logs.

Pass `--api` and `--org` to override the first two for a single invocation.
