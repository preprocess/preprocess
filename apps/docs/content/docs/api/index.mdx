## Rate limits

Requests are counted in one-minute windows:

| What is counted                                                                       | Limit per minute |
| ------------------------------------------------------------------------------------- | ---------------- |
| Every `/v1/orgs/{org}` request in one organization, from people and API keys together | 2,400            |
| Requests made with one API key                                                        | 600              |
| Sign-in, sign-up and emailed-link requests from one IP address                        | 30               |

A request over a limit gets `429 Too Many Requests` with a `Retry-After` header
giving the seconds until the window resets, and this body:

```json
{
  "error": "rate_limited",
  "message": "Too many requests. Try again in 12 seconds."
}
```

Wait for `Retry-After` before sending again. Spread work across several API keys
if one integration needs more than its key's share; they still share the
organization's limit.
